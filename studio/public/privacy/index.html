Privacy — The Benchmark Studio

Operator and contact

The Benchmark Studio is a Wolff Solutions project. This notice covers this app, rather than every linked product. For privacy questions or requests, email contact@wolff.solutions. The product name identifies this project; third-party names and marks belong to their respective owners.

Local workspace

Studio binds to your computer’s loopback interface. Benchmark settings, prompts, generated outputs, timings, logs and run artifacts are stored in the local workspace, including out/studio. There is no Wolff Solutions account or central results upload in this interface.

Model endpoints and tools

Studio accepts loopback model endpoints only. Starting a run sends prompts and task inputs to that local model service. The separate benchmark CLI can be configured differently, including with remote providers. Agentic benchmarks can execute tools and harness tasks; downloaded tools or a local service may themselves make network requests. Use synthetic inputs and review endpoint and tool settings before running.

Retention

You control local result files and model server logs. Delete saved runs and their artifacts from your workspace when no longer needed. Deleting a local run does not delete remote-provider logs. Package downloads and container or model services can make additional network requests.

Retention and your choices

You can clear this site’s browser data in your browser settings. This does not delete records already sent to a server or another provider. Contact us to request access, correction or deletion of information we control, or to ask about retention. We may need to verify your request and retain information needed for security or legal obligations. Do not send passwords, API keys or access tokens by email.
