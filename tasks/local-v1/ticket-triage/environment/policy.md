Departments: billing for charges, invoices, refunds; technical for software bugs/outages; sales for plans/pricing; other otherwise. If a ticket spans departments, billing takes precedence, then technical, then sales. Priority: high when all work is blocked with no workaround; medium when some function is broken but a workaround exists; low otherwise. refund_requested: true only when the customer explicitly requests money back; false for denial, a question about policy, or no request.
